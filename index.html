Claude Code 外掛程式（Plugins）

指南

📌 一句話說明

外掛 = 把技能、子代理、掛鉤、MCP 連線打包成一包，一行指令就能安裝、分享、做版本控管。

沒有外掛時，這些東西散落在專案的 .claude/ 資料夾裡，只有你自己那台電腦有；做成外掛後可以透過「市集」發佈，團隊或社群一行指令就裝好。

兩種做法的差別：放 .claude/ 叫用時是 /hello；做成外掛叫用時是 /外掛名:hello（自動加命名空間避免撞名）。建議先用 .claude/ 快速試，要分享時再轉外掛。

🧩 外掛可以包含哪些東西

元件放在哪做什麼
Skills
技能		skills/名稱/SKILL.md寫成 Markdown 的知識或流程。Claude 判斷情境自動載入，也可以打 /名稱 手動叫
Agents
子代理		agents/專職子代理，例如「PR 審查員」「資安審查員」，有自己的提示詞與工具權限
Hooks
掛鉤		hooks/hooks.json在特定事件自動觸發指令，例如「每次改完檔案就跑 lint」
MCP servers.mcp.json連外部服務（GitHub、Slack、Figma、資料庫…），免手動設定
LSP servers.lsp.json語言伺服器。Claude 改完程式立刻看到型別錯誤、能跳轉定義與找引用
Monitors
背景監看		monitors/monitors.json背景盯著 log 或檔案，有動靜就主動通知 Claude
⚠️ 最常見的錯誤：只有 plugin.json 放在 .claude-plugin/ 裡，其他資料夾一律放外掛根目錄。

⬇️ 怎麼安裝（三步驟）

1. 加市集　市集是別人整理好的外掛目錄。加了只是能瀏覽，還沒裝任何東西。

/plugin marketplace add anthropics/claude-plugins-community

2. 瀏覽　開管理面板，用 Tab 切換 Discover／Installed／Marketplaces／Errors／Stats 五個分頁。

/plugin

3. 安裝　指定「外掛名@市集名」。

/plugin install github@claude-plugins-official
官方市集 claude-plugins-official 第一次啟動 Claude Code 時會自動加好，不用手動加。安裝時可選範圍：User（自己所有專案）、Project（這個 repo 的所有協作者）、Local（只有自己、只在這個 repo）。

🏪 官方市集有什麼

類別內容
程式碼智能
(LSP)		typescript-lsp、pyright-lsp、gopls-lsp、rust-analyzer-lsp 等 11 種語言。需自行先裝該語言的 language server 執行檔
外部整合版控 github、gitlab；專案管理 atlassian、asana、linear、notion；設計 figma；基礎設施 vercel、firebase、supabase；通訊 slack；監控 sentry
資安審查security-guidance：Claude 每改一次程式就自動掃常見漏洞，並在同一輪對話中修掉
開發流程commit-commands（git 提交／推送／開 PR）、pr-review-toolkit（PR 審查代理）、plugin-dev（做外掛的工具包）、agent-sdk-dev
輸出風格explanatory-output-style（解釋實作取捨）、learning-output-style（互動教學模式）

⌨️ 指令速查

指令用途
/plugin開管理面板：瀏覽、安裝、停用、看錯誤、看 token 用量
/plugin marketplace add <來源>加市集。支援 GitHub owner/repo、Git URL、本機路徑、遠端 JSON
/plugin install <名>@<市集>安裝外掛
/plugin list列出已安裝，可加 --enabled 或 --disabled
/plugin disable｜enable｜uninstall停用／啟用／移除
/reload-plugins不重開就套用變更；卡住時加 --force
claude --plugin-dir ./我的外掛開發中直接載入本機外掛測試，不必先發佈
claude plugin validate ./我的外掛送審社群市集前先自我檢查
小提醒：/plugin 是終端機 CLI 的互動面板。桌面版或雲端 session 沒有這個指令時，改用桌面版的外掛瀏覽器，或直接在 .claude/settings.json 的 enabledPlugins 宣告。

🛠️ 自己做一個（最小骨架）

my-first-plugin/
├── .claude-plugin/
│   └── plugin.json     <- 只有這個檔放這裡
└── skills/
    └── hello/
        └── SKILL.md

plugin.json

{
  "name": "my-first-plugin",
  "description": "A greeting plugin",
  "version": "1.0.0"
}

SKILL.md（$ARGUMENTS 會接住使用者輸入的文字）

---
description: 用親切的方式跟使用者打招呼
---

跟名叫 "$ARGUMENTS" 的使用者打招呼，並問今天能幫上什麼忙。

測試：claude --plugin-dir ./my-first-plugin，然後打 /my-first-plugin:hello 小明。

懶得手打骨架就用 claude plugin init my-tool，它會在 ~/.claude/skills/ 生成好，下次開 session 自動載入，連市集都不用。

⚠️ 安全提醒

外掛是高度信任的元件，安裝後能以你的使用者權限在你的電腦上執行任意程式碼。Anthropic 不控制、也無法驗證第三方外掛裡包了什麼 MCP server 或檔案。

  • 只裝你信任來源的外掛與市集
  • 安裝前看 Will install 區塊，它會列出這個外掛會加入哪些指令、代理、技能、掛鉤、MCP／LSP server
  • 也看 Context cost：每個外掛都會吃掉每一輪對話的 token 額度
  • 用不到就停用——面板的 Not used recently 會標出長期沒用到的外掛
